# Balorg-mine
Resource extraction and system mining

## Features
- System information extraction
- Resource metrics collection
- Logging and data storage

## Build
```bash
./build.sh
```

## Run
```bash
# Shell version
cd src
./balorg_mine.sh

# Python version
python3 balorg_mine.py
```

## Output
- Logs: `logs/mining.log`
- Data: `data/`
